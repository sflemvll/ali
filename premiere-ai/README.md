# مساعد Adobe Premiere Pro الذكي 🎬🤖

تكتب بالمحادثة شنو تريد بالعربي — والذكاء ينفّذه فعلياً داخل بريمير:
يستورد ملفات، يرصّها على التايم لاين، يقصّ، يضيف انتقالات وتأثيرات، يحط ماركرات،
ويصدّر… وكل هذا بدون ما تلمس الماوس.

> مثال: «استورد كل الفيديوات من مجلد Footage، حطهم على V1 بالترتيب، وحط بينهم
> Cross Dissolve نص ثانية، وحط ماركر كل دقيقة».

---

## شلون يشتغل؟

```
┌──────────────────────┐   WebSocket    ┌──────────────────────┐   HTTPS   ┌────────────┐
│  لوحة داخل بريمير    │ ◄────────────► │  سيرفر بايثون محلي   │ ◄───────► │   Claude   │
│  (CEP Panel + chat)  │                │  (FastAPI + SDK)     │           │  opus-5    │
└──────────┬───────────┘                └──────────────────────┘           └────────────┘
           │ evalScript
           ▼
┌──────────────────────┐
│ ExtendScript داخل    │
│ Premiere (app.project│
│  + QE DOM + AI.*)    │
└──────────────────────┘
```

1. تكتب طلبك في اللوحة داخل بريمير.
2. اللوحة ترسله للسيرفر المحلي، والسيرفر يمرّره لـ Claude مع وصف كامل لواجهة بريمير البرمجية.
3. Claude يقرأ حالة المشروع أولاً (`AI.state()`)، ثم يكتب كود ExtendScript.
4. اللوحة تنفّذ الكود داخل بريمير وترجّع النتيجة (أو الخطأ) للذكاء.
5. إذا صار خطأ، الذكاء يصحّح نفسه ويعيد المحاولة — لحد ما يخلص، وبعدها يجاوبك بالعربي.

**مهم:** المفتاح والسيرفر يشتغلان على جهازك فقط (`127.0.0.1`). الوحيد اللي يطلع برّه
هو نص المحادثة + حالة المشروع (أسماء الكليبات والتوقيتات) اللي يحتاجها الذكاء —
ملفات الفيديو نفسها ما تنرفع لأي مكان.

## التثبيت

### 1) المتطلبات
- Adobe Premiere Pro 2019 (13.0) أو أحدث
- Python 3.9+
- مفتاح API من Anthropic (`sk-ant-...`)

### 2) نصّب اللوحة

**ويندوز** — دبل كلك على:
```
premiere-ai\install\install_windows.bat
```

**ماك** — من الترمنال:
```bash
bash premiere-ai/install/install_mac.sh
```

السكربت يسوي شغلتين: يفعّل `PlayerDebugMode` (ضروري للإضافات غير الموقّعة)،
وينسخ/يربط اللوحة بمجلد إضافات CEP.

### 3) حط المفتاح
```bash
cd premiere-ai/server
cp .env.example .env      # ويندوز: copy .env.example .env
```
وافتح `.env` وحط:
```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxx
```

### 4) شغّل السيرفر
**ويندوز:** `premiere-ai\install\start_server.bat`
**ماك/لينكس:** `bash premiere-ai/install/start_server.sh`

لازم تشوف: `→ السيرفر يشتغل على http://127.0.0.1:8777`

### 5) افتح اللوحة داخل بريمير
```
Window → Extensions → مساعد الذكاء الاصطناعي — AI Assistant
```
إذا صارت النقطة خضراء ومكتوب «متصل» — كلشي تمام، ابدأ اكتب.

## أمثلة على الطلبات

| تكتب | يسوي |
|------|------|
| «شنو موجود بالتايم لاين؟» | يقرأ التسلسل ويعطيك ملخص المسارات والكليبات |
| «استورد C:/videos/a.mp4 وb.mp4 وحطهم على V1» | استيراد + رصّ على المسار |
| «قصّ عند الثانية 12 و 30 واحذف الجزء اللي بينهم» | razor + حذف مع ripple |
| «حط Cross Dissolve بين كل الكليبات نص ثانية» | يمرّ على كل الكليبات ويضيف الانتقال |
| «خلّي الكليب الثاني بسرعة 200%» | `setSpeed` عبر QE DOM |
| «كبّر الكليب الأول 120% وحرّكه لفوق شوية» | تعديل خصائص Motion |
| «حط ماركر كل دقيقة لنهاية التسلسل» | حلقة ماركرات |
| «صدّر التسلسل على D:/out.mp4 بإعداد كذا» | `exportAsMediaDirect` أو طابور AME |
| «شنو تأثيرات البلور المتوفرة؟» | يقرأ قائمة التأثيرات من QE |

## الإعدادات داخل اللوحة (زر ⚙)

- **عنوان السيرفر** — غيّره إذا بدّلت المنفذ.
- **تنفيذ تلقائي** — إذا طفّيته، كل أمر يظهرلك بالكود مع زر «نفّذ / ارفض» قبل ما يشتغل.
  ينصح بتطفيته أول ما تجرّب، لحد ما تثق بالنتائج.
- **إظهار الكود** — يعرض كل كود ينفّذ داخل بريمير (مفيد للتعلّم والتشخيص).
- **محادثة جديدة** — يمسح ذاكرة المحادثة (المشروع ما يتأثر).

## بنية المشروع

```
premiere-ai/
├── server/
│   ├── app.py            # سيرفر FastAPI + WebSocket للوحة
│   ├── agent.py          # حلقة Claude (أدوات + تصحيح ذاتي)
│   ├── bridge.py         # ربط طلبات التنفيذ بنتائجها
│   ├── prompts.py        # توجيه النموذج + توثيق واجهة بريمير + تعريف الأدوات
│   └── requirements.txt
├── extension/            # لوحة CEP اللي تنفتح داخل بريمير
│   ├── CSXS/manifest.xml
│   ├── index.html · css/style.css · js/main.js · js/CSInterface.js
│   └── jsx/host.jsx      # مكتبة AI.* بلغة ExtendScript
├── tests/                # اختبار بدون بريمير (محاكي + Claude مُصطنع)
└── install/              # سكربتات التثبيت والتشغيل
```

### اختبار بدون بريمير
تكدر تتأكد أن السيرفر والجسر ومكتبة `AI.*` شغّالة قبل ما تفتح بريمير أصلاً
(يحتاج `node` موجود على الجهاز):

```bash
cd premiere-ai/tests
ANTHROPIC_API_KEY=dummy python test_flow.py
```

الاختبار يشغّل سيرفراً حقيقياً + لوحة وهمية + محاكي بريمير بـ node، ويتأكد أن
الكود يوصل «لبريمير» وأن النتيجة ترجع للنموذج. ما يستهلك أي رصيد API.

### مكتبة `AI.*` الجاهزة
`host.jsx` تعطي الذكاء دوال مختصرة بدل ما يكتب كود خام كل مرة:
`AI.state()` · `AI.importFiles()` · `AI.append()` · `AI.insertAt()` · `AI.razor()` ·
`AI.removeClip()` · `AI.moveClip()` · `AI.setClipSpeed()` · `AI.addTransition()` ·
`AI.addEffect()` · `AI.listEffects()` · `AI.setClipProperty()` · `AI.addMarker()` ·
`AI.setPlayhead()` · `AI.newSequence()` · `AI.exportSequence()` · `AI.saveProject()`

تكدر تزيد دوالك الخاصة بنفس الملف، وتضيف وصفها في `prompts.py` حتى الذكاء يعرف بيها.

## حلول المشاكل الشائعة

| المشكلة | الحل |
|---------|------|
| اللوحة ما تظهر بقائمة Extensions | ما انفعّل `PlayerDebugMode` — أعد تشغيل سكربت التثبيت ثم أعد تشغيل بريمير كاملاً |
| اللوحة بيضاء / فاضية | افتح `http://localhost:8088` من المتصفح وبريمير شغّال، وشوف أخطاء الكونسول |
| «غير متصل بالسيرفر» | السيرفر مو شغّال، أو المنفذ 8777 محجوز — غيّر `PREMIERE_AI_PORT` والعنوان باللوحة |
| «EvalScript error» | خطأ في كود ExtendScript — الذكاء عادةً يصحّح نفسه؛ إذا تكرر، افتح «إظهار الكود» وشوف وين يوقف |
| ما يلگى المفتاح | ملف `.env` لازم يكون داخل `premiere-ai/server/` وبنفس الاسم `.env` بالضبط |
| العملية تعلّق | بريمير فاتح نافذة تنتظر ضغطة (استيراد/تصدير) — سكّرها ورجّع جرّب |

## حدود ومحاذير

- الواجهة البرمجية لبريمير ما تغطي كلشي: تحريك الكيفريمات المعقّد، Lumetri المتقدّم،
  والـ Essential Graphics القوالب — دعمها محدود أو يحتاج قوالب MOGRT جاهزة.
- **Undo** داخل بريمير يتراجع عن خطوة وحدة بالمرة، فالعمليات الكبيرة صعب التراجع عنها
  دفعة وحدة — احفظ نسخة من المشروع قبل التجارب الكبيرة.
- ExtendScript لغة ES3 قديمة (بدون `let/const/JSON/arrow`) — الذكاء متعلّم هذا الشي
  بالتوجيه، بس إذا كتبت كود يدوي انتبه.
- CEP هي الطريقة المدعومة على أوسع نطاق حالياً؛ Adobe تتّجه لـ UXP مستقبلاً، وقتها
  يتغيّر ملف اللوحة بس منطق السيرفر يبقى نفسه.
